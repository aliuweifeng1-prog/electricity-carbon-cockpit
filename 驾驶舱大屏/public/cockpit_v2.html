模型自校正 · 线路阻抗在线参数辨识 应用校正到模型 ⟳
辨识原理：比较每条支路的"实测电压降"与"按登记阻抗预测的电压降"，其比值即真实阻抗相对登记值的倍数，取多帧中位数作为结论。
为什么不用最小二乘分别辨识 R、X：配电网负荷功率因数基本恒定，P 与 Q 近似成固定比例，回归量高度共线，协方差矩阵病态会导致数值发散（实测中估计值曾跑到 +170%，而真值仅 +8%）。中位数比值法不受离群点影响，结论稳定且易于向运维解释。
可观测性前提：园区低压线路压降仅十几伏，需 0.2 级及以上精密表计（±0.1%）。若用常规 0.5 级表，±2V 的噪声会直接淹没 10% 量级的阻抗偏差信号，辨识在物理上不成立。

口径诊断日志
口径不可混用：年均AEF（生态环境部核算口径、GHG Protocol Scope 2 location-based）是年度常数，对时间梯度恒为零，用于调度优化时数学上不产生任何信号——切到该口径可自行验证减排量恒为0。逐时AEF（对应国际24/7 CFE Compact、EnergyTag颗粒度证书方向）适合逐时匹配核算。边际MEF（WattTime等采用）回答"边际那度电由谁发"，是调度决策的正确口径。对外披露须用AEF，内部优化须用MEF。
数值来源：年均AEF取生态环境部公布的全国电网平均排放因子 0.5366 kgCO₂/kWh（2022年度值，需按最新公布年份及所属区域电网因子更新）。碳价参考值（CEA约100元/t、欧盟ETS约620元/t）为量级性引用，须按当期行情核实。
实测口径：英国GB取 National Grid ESO / Carbon Intensity API 官方半小时实测消费侧碳强度（2026-08-01，actual字段，48点完整）；波兰PL取 energy-charts.info（Fraunhofer ISE）实测分燃料出力，按直接燃烧排放因子反算AEF（2026-08-01，夜/午/晚峰三窗口实测后插值，非全天连续实测）。两者均为境外电网结构对标，不是华东实测——公开渠道不存在可取的中国区域电网逐时MEF实测数据：生态环境部按CDM体系发布的OM电量边际因子是年度值而非逐时，国内"动态碳排放因子"研究多为省级成果且未开放数据集。
合成口径已被实测数据否证：原MEF合成曲线假设午间边际因子下探至0.18（峰谷差0.84），前提是边际机组变为被弃的新能源。波兰实测显示，在新能源占负荷达50%、抽蓄以约1000MW吸收余电的情况下弃电并未发生，退让的是煤电——褐煤由夜间全平基荷（波动70MW）转为午间主动深调（波动324MW），边际机组仍是煤。故实测峰谷差仅0.33（波兰）与0.12（英国），合成曲线高估2.5至7倍。请以实测口径的结论为准。
模型边界：本视图仍止于并网点，PCC为定压平衡节点，配网侧无约束下发、园区侧无能力上报。碳排口径为电网侧间接排放（Scope 2），未含园区自身直接排放（Scope 1）与上游供应链（Scope 3）。

配网协同诊断日志
模型边界：戴维南等值建模的是 PCC 对上级馈线的外部阻抗，采用两次迭代（内部潮流→算净购电→修正 vSlack→重算），误差 <0.01%。PCC 电压偏差量级取决于 Ssc：10 MVA 典型馈线下最大购电150kW 对应偏差约 -0.9%，处于 ±7% 合格范围内；弱网（2 MVA）下可达 -4.5%，接近越限需触发减载。
约束机制：三种配网约束采用大 M 软约束（惩罚系数 10⁵ 元/kWh），DP 总能找到最优可行解。当储能容量不足以同时满足所有约束（如 DR 削减量超过可放电量）时，取违约量最小方案并在日志里告知——这正是能力申报应给出的上限值。
能力上报说明：RegUp/RegDown 为单时段保守估算，基于当前 SOC 裕量和功率余量。实际 VPP 申报需做前向仿真（连续多时段联合约束），此处为演示性简化版，数值应视为上界而非可直接申报值。
